# Codex Goal Mode DFlash Deck

Static HTML slides for presenting the clean-room MLX DFlash implementation and
the Codex goal-mode experiment loop.

## View locally

Open `presentation/index.html` in a browser.

Keyboard controls:

- Right arrow, Page Down, or Space: next slide
- Left arrow or Page Up: previous slide
- Home: first slide
- End: last slide

## Publish with GitHub Pages

The deck is dependency-free and can be served directly by GitHub Pages. If Pages
is configured to publish from the repository root, the deck will be available at
`/presentation/`.
